Overview

A memory score should say whether the scene was set, whether the asked change was carried out, and whether the last frame shows the result. Current tests fold these into one number, so a low score is easy to read as forgetting. MIST separates them. M3-Agent reads the failed last frame and revises only that move. The clip that is kept is chosen by the same score that reports the result, so the ceiling is an oracle.
